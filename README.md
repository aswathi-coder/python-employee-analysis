# python-employee-analysis
Employee dataset analysis project
This project focuses on analyzing employee data from ABC Company using Python. The dataset contains 458 employee records with 9 different attributes related to employee details such as team, position, age, salary, and height.
The main objective of the project is to preprocess the dataset, perform data analysis, generate meaningful visualizations, and derive useful business insights from the data.
The project was implemented using Python with libraries such as Pandas, NumPy, Matplotlib, and Seaborn.
# Analysis Tasks Performed
Distribution of Employees Across Teams
Employee Segregation Based on Position
Predominant Age Group Analysis
Highest Salary Expenditure Analysis
Correlation Between Age and Salary
